# 🧮 Métodos Numéricos - Python Scripts

Este repositorio contiene las implementaciones en Python de diversos algoritmos de análisis numérico desarrollados a lo largo del semestre. 

El objetivo principal de estos scripts es resolver problemas matemáticos complejos mediante aproximaciones computacionales, iteraciones y optimización de recursos, minimizando el margen de error.

## 📂 Estructura del Repositorio

El código está organizado en los siguientes directorios según el método matemático aplicado:

* **`Derivacion_numerica/`**: Cálculo de derivadas aproximadas utilizando métodos de diferencias finitas.
* **`Euler/`**: Resolución numérica de Ecuaciones Diferenciales Ordinarias (EDOs) de primer orden para problemas de valor inicial.
* **`Gauss-Seidel/`**: Algoritmo iterativo para la solución de sistemas de ecuaciones lineales.
* **`Newton_Raphson PY/`**: Método de aproximaciones sucesivas para encontrar raíces reales de funciones no lineales.
* **`Polinominal/`**: Ajuste de curvas e interpolación de puntos de datos.
* **`Simpson/`**: Integración numérica para aproximar el área bajo la curva utilizando parábolas.

## 🚀 ¿Cómo utilizarlos?

1. Clona este repositorio en tu entorno local:
   ```bash
   git clone [https://github.com/M1ck-M1sael/Metodos-Numericos-Scripts-Python.git](https://github.com/M1ck-M1sael/Metodos-Numericos-Scripts-Python.git)

2. Asegurate de tener Python 3.x instalado

3. (Opcional) Algunos de los Scripts, requieren instalar dependencias para generar gráficas o manejar arreglos. Las dependencias son NumPy o Matplotlib.
**Comando de instalación:** pip install numpy matplotlib

4. Navega a la carpeta del método deseado y ejecuta el script pricnilap correspondiente.
